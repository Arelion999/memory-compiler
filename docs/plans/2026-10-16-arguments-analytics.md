# Валидация аргументов и честная аналитика поиска

> Исполнение: subagent-driven-development, затем независимое ревью и встроенный code-review с medium.

**Цель:** неподдерживаемые поля и неверные типы получают понятную ошибку до обработчика; технические ошибки поиска не считаются пустыми результатами.

**Согласование:** владелец 16.10 поручил исправить два пункта аудита 15.10 и проверить тестами. Выбран предложенный в отчёте явный отказ; молчаливое удаление полей и расширение search(limit)/finish_task(verified) изменили бы контракт и скрыли ошибку клиента.

**Архитектура:** использовать объявленные схемы как источник допустимых параметров. Сохранить существующие heal_arguments, project fallback и служебный _client_session; валидировать после восстановления аргументов и до dispatch. Ошибка не содержит значений аргументов, не запускает handler/запись/freshness и учитывается аудитом как ошибка. Сохранить существующий успешный формат выдачи, включая search structuredContent. Возвращать MCP tool error (`isError`) совместимым с SDK способом; не менять required outputSchema и не добавлять default в схемы.

**Аналитика:** searches — число попыток, search_errors — число отказов, successful_searches — число успешных вызовов. misses/empty results и miss_rate относятся только к успешным поискам. act_rate также имеет явный знаменатель успешных поисков. Не засчитывать неуспешное чтение/запись как полезное действие. Сбой следующего поиска завершает связь предыдущего с будущим действием, не позволяя приписать ему чужой успех. Сохранить legacy `_count` / size fallback для успешных исторических строк. Согласовать сервер, UI, daily и автономный hooks stats.

**Технологии:** Python, MCP SDK 1.29.1, pytest, существующие JSON schemas, Web UI JavaScript и i18n RU/EN. Без изменения SDK/поискового ранжирования/серверных сессий/клиентских установок.

## Приёмка

Главный агент проверяет фактический вывод тестов, независимый reviewer сначала сверяет scope/спеку, затем корректность/регрессии. Встроенный code-review текущего diff с medium; находки исправляются или отклоняются с причиной. git diff --check и git audit-secrets перед локальным коммитом. Сообщение коммита по-русски, без Co-Authored-By. Push запрещён без отдельного разрешения. Релиз/деплой в эту задачу не входит. Итог записать в Memory Compiler, указать Git status/ahead и ограничения проверки.
